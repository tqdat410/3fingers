# 3fingers

A compact workspace for reading several social feeds in desktop Chrome.

## Brand

- Primary: charcoal `#1C1C1C` (`--brand-primary`), sampled from the official logo. Light mode uses white surface, `#F7F7F7` canvas, `#686868` muted text and `#E5E5E5` borders. Dark mode uses `#1C1C1C` surface, `#242424` canvas, `#F1F1F1` text, `#AAAAAA` muted text and `#393939` borders. Focus and icons follow text contrast; errors retain their own color.
- Font: bundled, unmodified Ubuntu 400/500/700 TTF from Google Fonts under UFL 1.0. System fonts cover missing glyphs, including Vietnamese. No font requests or font changes inside social pages.
- Logo: original 1254 x 1254 RGBA PNG at `extension/assets/brand/logo-original.png`. Icons at 16/32/48/128 crop the visible area with padding and preserve transparency. Header, favicon and extension action share the logo. The popup's dark variant renders the existing mark white while preserving alpha, with no background badge or border; light mode retains the charcoal mark.
- Title: `3fingers`. Extension description: `Read social feeds side by side with synced scrolling.` Fixed quote: `Multitask is not real!` Preserve the quote's exact wording, capitalization and punctuation. Show it once below the brand in the popup, with no repeated quote in the title/header, and in the README. All extension labels, tooltips, status messages, errors and accessibility text use short English. Localized site matching and multilingual test data remain functional data.

## Layout and controls

- Up to three equal-width panels. New workspaces show Facebook, Threads and Instagram with an Open button. Older surplus panels are saved for restoration. No simulated feeds or repeated permission descriptions.
- No main toolbar in the workspace or vertical separators between social panels. The Chrome action opens a 300px popup. Its logo/name/quote group aligns to the left padding. A compact 44px square Open workspace button on the right echoes the logo’s rounded silhouette, with an inverted text/surface palette and oversized bold 48px `Go` lettering, optically centered in both axes and cropped by the rounded silhouette to echo the logo’s cutout detail. Hover softens the fill; pressing scales the button slightly. Reduced motion removes these movements. No setup hint is shown when the workspace is closed. GitHub link, tool light/dark, Reload all and + remain below. GitHub opens https://github.com/tqdat410/3fingers. Opening the workspace focuses an existing tab or creates one. Controls target the active workspace in the current window when available. Reload all starts all permitted panels together; it is disabled when no panels are enabled. + is disabled at three sites. An empty workspace points to the extension menu. Popup content has no outer border; Chrome draws its own native bubble frame outside the page.
- Panel toolbar: 32px, reload then site sun/moon on the left, supplied pin icon centered at 18px, change-site and close on the right. Buttons are 28px for a compact desktop layout, with tooltips, keyboard focus and accessible names. Pin/icon contrast follows the tool theme. No management menu, resize controls or separate site-name bar.
- Panel site picker: anchored to its button, with Facebook, Instagram, Threads and TikTok. No title, footer or backdrop. Supports outside dismissal, Escape, arrow keys, Home, End and Enter. Stays within the viewport. The popup's + reveals the same social choices and any saved sites for restoration. Duplicate sites are allowed.
- Click the pin to toggle independent scrolling. Outline joins sync; solid excludes the panel as both source and follower. Enter/Space toggle; arrow keys reorder. Pin updates serialize configuration without applying disabled-opacity styling to every topbar button. Pin preferences stay with the panel through reload, reorder and site replacement. TikTok always uses native independent scrolling: show a solid pin with aria-disabled=true, preserve its keyboard reorder, and make pin clicks a no-op. Do not overwrite its stored pin preference; replacing it with another social restores that preference. There is no global sync toggle; rejoining keeps the current reading position.
- Drag empty space in the panel topbar at least 6px to reorder. Buttons and their icons never start dragging; the pin is click-only for pointer input. The panel scales to 0.96 and follows the pointer in both axes while showing its new position. Release saves; Escape cancels. Drag, cancel and keyboard ordering never toggle the pin. A single panel still supports pinning. Preserve iframe viewport, document and scroll offset without reloading.

## Scrolling and site content

- TikTok keeps native wheel, pointer, keyboard, playback, comments and Auto Scroll behavior. Its native movements never synchronize other feeds, and other feeds never move it. No custom auto-next, snap adapter or prefetch is added. Its theme control remains disabled until a native adapter is verified.
- Dragging other feed content scrolls that feed independently. A movement threshold preserves normal clicks. Inputs, small buttons, video controls, dialogs and nested scrollers keep native behavior. Shift allows text selection. Native touch scrolling stays local; wheel and keyboard sync only unpinned panels.
- Comments and dialogs scroll independently and pause their background feed. Sync resumes when the dialog closes. Connection and permission states remain distinct from a loaded site.
- Appending a page below the viewport preserves an active synchronized wheel gesture. Layout anchoring, shrinking, root replacement and viewport changes still reset the scroll baseline to avoid sending automatic movement to other feeds.
- Keep native navigation, posts, inputs, cards, media and comments. Theme controls select existing native light/dark palettes within each social document, preserving native shapes and media colors without filters. Choices persist per panel; unsupported structures keep native presentation. The separate tool theme affects popup, panel bars and extension components only. Hide only feed scrollbars. During a swipe, temporarily change the cursor and suppress selection. Do not crop, reparent or rebuild feeds or hide site controls. Compact reading mode remains out of scope.
- Site names and domains remain available in tooltips, accessible labels, the picker and unopened panels. No user content enters product analytics or logs.
- Controls remain reachable in narrow columns; desktop is the primary target. Respect reduced motion. Do not replace the layout with Chrome's two-tab split.

This is a local extension UI. SEO, sitemaps, AI discovery and sharing integrations are outside its scope.
